# Backend API Routes and Functionality for Art Gallery

## Authors (Авторы)
- `GET /api/v1/authors` - Get a list of all authors
- `GET /api/v1/authors/{id}` - Get author information by ID
- `POST /api/v1/authors` - Create a new author
- `PUT /api/v1/authors/{id}` - Update author information
- `DELETE /api/v1/authors/{id}` - Delete an author

## Artworks (Арт объекты)
- `GET /api/v1/artworks` - Get a list of all artworks
- `GET /api/v1/artworks/{id}` - Get artwork information by ID
- `POST /api/v1/artworks` - Create a new artwork
- `PUT /api/v1/artworks/{id}` - Update artwork information
- `DELETE /api/v1/artworks/{id}` - Delete an artwork
